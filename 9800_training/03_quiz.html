🧠 Category B: Concepts & Behavior
Q11.What is the primary function of the Site Tag on the Cisco 9800?
AMaps SSIDs to VLANs and defines client switching mode
BControls AP operating mode (Local vs FlexConnect) and references the AP Join Profile
CAssigns radio channel and transmit power settings per band
DDefines which RADIUS server to use for client authentication
💡 The Site Tag controls AP operating mode: if a Flex Profile is attached the AP enters FlexConnect mode; without it, the AP operates in Local mode. It also references the AP Join Profile which controls management settings.
Q12.What happens when you attach a Flex Profile to a Site Tag?
AAPs reboot into Mesh Bridge mode
BAPs switch to FlexConnect operating mode
CAPs enable local web authentication only
DAPs begin using local RADIUS instead of central AAA
💡 Attaching a Flex Profile to a Site Tag causes all APs referencing that tag to operate in FlexConnect mode. This allows local data switching at the AP/branch level.
Q13.Which profile directly controls the VLAN that wireless clients are placed on?
AAP Join Profile
BRF Profile
CPolicy Profile
DFlex Profile
💡 The Policy Profile contains the VLAN assignment for client traffic, along with the switching mode (Central/Local), ACL, and QoS settings. It is referenced by Policy Tags.
Q14.What is the name of the default Policy Tag on the Cisco 9800?
Aglobal-policy-tag
Bdefault-policy-tag
Csystem-policy-tag
Dbase-policy-tag
💡 The three default tags are: default-policy-tag, default-site-tag, and default-rf-tag. Any AP not explicitly assigned a custom tag inherits these defaults.
Q15.In a Policy Profile, what does enabling 'Central Switching' mean for client traffic?
AThe AP switches client traffic locally without involving the WLC
BAll client data frames are tunneled via CAPWAP to the WLC for forwarding
CThe WLC uses a central aggregated VLAN for all SSIDs simultaneously
DClients authenticate centrally but their data bypasses the WLC
💡 Central Switching means all client data frames are encapsulated in CAPWAP and sent to the WLC, which then forwards them into the wired network. This is the default mode for Local-mode APs.
Q16.How many Policy Tags, Site Tags, and RF Tags can a single AP have assigned simultaneously?
AMultiple of each — one per SSID
BOne Policy Tag, multiple Site Tags, one RF Tag
CExactly one of each tag type
DOne Policy Tag and one RF Tag, unlimited Site Tags
💡 Each AP has exactly ONE Policy Tag, ONE Site Tag, and ONE RF Tag at any given time. This is a fundamental constraint of the 9800 configuration model.
Q17.Which 802.11 standard introduced the 6 GHz band (Wi-Fi 6E)?
A802.11ac (Wi-Fi 5)
B802.11ax limited to 5 GHz only
C802.11ax extended to include 6 GHz (Wi-Fi 6E)
D802.11be (Wi-Fi 7)
💡 Wi-Fi 6E extends 802.11ax into the 6 GHz band (5.925–7.125 GHz), providing additional spectrum free of legacy device interference. Cisco 9130AXE and 9136 series support 6 GHz.
Q18.A FlexConnect AP loses its WAN connection to the WLC. With Local Switching configured, what happens to connected clients?
AAll clients are immediately deauthenticated
BClients remain connected; traffic is switched locally at the AP (standalone mode)
CThe AP reboots and clients must reconnect via 4G backup
DClients are moved to a fallback SSID with degraded connectivity
💡 FlexConnect APs in standalone mode (WAN down) continue to switch client traffic locally. Clients with locally switched SSIDs remain connected. New client authentication uses cached credentials or a local RADIUS server.
Q19.The 'Enable Local Site' checkbox in a Site Tag is unchecked. What does this indicate?
AThe AP will not broadcast any SSIDs locally
BThe APs are at a remote/branch site — typically used with FlexConnect
CThe site has no physical APs — it is a virtual site
DLocal DHCP is disabled for this site
💡 Unchecking 'Enable Local Site' signals that APs are at a remote site (not directly connected to the WLC). Combined with a Flex Profile, this puts APs into FlexConnect remote-branch mode.
Q20.What High Availability mechanism does the Cisco 9800 WLC use for controller redundancy?
AHSRP (Hot Standby Router Protocol) in Active/Standby
BStateful Switchover (SSO) with a dedicated HA port
CVRRP (Virtual Router Redundancy Protocol)
DActive/Active clustering with load balancing
💡 The 9800 uses Stateful Switchover (SSO) for HA. The primary and secondary WLCs synchronize state over a dedicated HA port. On failover, client sessions are maintained (stateful) with minimal disruption.
🎯 Category C: Scenarios
Q21.An AP joins the WLC and clients associate, but they receive the wrong VLAN. What is the most likely cause?
AThe RF Tag is pointing to the wrong RF Profile
BThe Policy Profile has an incorrect VLAN configured
CThe Site Tag is missing a Flex Profile
DThe AP Join Profile has incorrect NTP settings
💡 Client VLAN assignment is controlled by the Policy Profile. If clients are landing on the wrong VLAN, the Policy Profile referenced in the Policy Tag has the wrong VLAN configured.
Q22.You create a new WLAN and set Status = Enabled, but the SSID is not visible on any client device. What must you check first?
AThe RF Tag must explicitly reference this WLAN
BThe WLAN must be mapped in a Policy Tag, and that tag must be assigned to APs
CThe WLAN must be linked to the AP Join Profile
DThe Site Tag must include the WLAN name in its configuration
💡 A WLAN profile alone does not broadcast. It must be: (1) Enabled, (2) mapped to a Policy Profile in a Policy Tag, and (3) the Policy Tag must be assigned to APs. Missing any of these three steps causes the SSID to not broadcast.
Q23.A branch office has 3 APs in FlexConnect mode. The WAN link fails. Which clients lose connectivity?
AAll clients — FlexConnect requires constant WLC connectivity
BOnly new clients trying to join; existing locally-switched clients stay connected
COnly clients on central-switched SSIDs; locally-switched clients stay connected
DAll clients on 5 GHz; 2.4 GHz clients are unaffected
💡 During a WAN outage, FlexConnect APs enter standalone mode. Clients on locally-switched SSIDs remain connected. Clients on centrally-switched SSIDs lose connectivity because their data must reach the WLC.
Q24.An AP is stuck in 'Discovering' state and never joins the WLC. What should you check FIRST?
AVerify the RF Tag is correctly assigned to the AP
BVerify CAPWAP connectivity: DNS resolution, DHCP option 43, or controller IP reachability
CVerify the Policy Tag contains at least one WLAN mapping
DEnsure the AP is running the same IOS-XE version as the WLC
💡 An AP in Discovering state has not established a CAPWAP control channel with the WLC. Check: DNS lookup for 'CISCO-CAPWAP-CONTROLLER.localdomain', DHCP option 43 (controller IP), or static controller IP configured on the AP. Tags are irrelevant if the AP cannot even reach the WLC.
Q25.Users on Floor 5 report intermittent drops every 3–5 minutes at the same time every day. What tool do you use FIRST to investigate?
ARadioactive Trace on affected client MACs
BMonitoring › RF › Spectrum (CleanAir) to check for interference
CPacket Capture on the AP radio
DMonitoring › Wireless › Rogues
💡 Periodic, time-based interference (every few minutes) strongly suggests a non-802.11 device such as a microwave oven, DECT phone, or wireless video camera. CleanAir Spectrum analysis is the correct first step to identify the source.
Q26.A security audit requires per-user dynamic VLAN assignment from RADIUS for 802.1X clients. Which setting must be enabled in the Policy Profile?
ACentral DHCP
BAAA Override
CNAC (Network Admission Control)
DWeb Policy
💡 AAA Override must be enabled in the Policy Profile to allow RADIUS to dynamically override the VLAN, ACL, or QoS policy on a per-client basis using Cisco VSA attributes (e.g., Tunnel-Private-Group-ID for VLAN).
Q27.After upgrading the WLC from 17.9.3 to 17.9.5, several APs show 'Image Mismatch' status. What is the correct action?
ADelete and re-add the APs from the WLC
BReset the Site Tag on the affected APs to trigger a reload
CTrigger AP image pre-download and then reload the affected APs
DDowngrade the WLC back to 17.9.3 to match the APs
💡 Image Mismatch means the AP image version does not match the WLC. Navigate to Administration › Software Management and trigger an AP Pre-download. APs will download the correct image and reload to resolve the mismatch.
Q28.You need two SSIDs on the same AP: one corporate (central switching, VLAN 10) and one guest (local switching, VLAN 200). What is required?
ATwo separate WLANs with two Policy Profiles, both mapped in one Policy Tag
BTwo separate Policy Tags — one per SSID — both assigned to the same AP
COne WLAN with dual-VLAN configuration in the Policy Profile
DTwo APs — one cannot serve both central and local switching simultaneously
💡 One Policy Tag can contain multiple WLAN-Policy mappings. Create two WLANs (Corp and Guest), two Policy Profiles (central switching VLAN 10, local switching VLAN 200), and map both in the same Policy Tag assigned to the AP.
Q29.An 802.1X client connects but Radioactive Trace shows the RADIUS server returning an Access-Reject. The network team confirms the server is healthy. What is the most likely issue?
AThe RF Tag is missing a 5 GHz RF Profile
BThe RADIUS shared key on the WLC does not match the server configuration
CThe Site Tag has Local Site unchecked
DCentral DHCP is disabled in the Policy Profile
💡 Access-Reject (not a timeout or unreachable) means the RADIUS server received and processed the request but denied it. The most common cause when the server is known healthy is a shared-key mismatch — the RADIUS server cannot decrypt the authentication request and rejects it.
Q30.You want to capture the actual EAPOL frames exchanged between a client and an AP. Which tool provides this?
ARadioactive Trace — it captures EAPOL at the control-plane level
BTroubleshooting › Packet Capture on the AP radio
CMonitoring › Wireless › Clients › Client Detail
DAdministration › Logging with debug dot1x enabled
💡 Packet Capture on the AP radio captures raw 802.11 frames over the air, including EAPOL. The resulting .pcap file shows the exact EAP message exchange. Radioactive Trace shows the WLC-side control-plane view, not the raw frames.
