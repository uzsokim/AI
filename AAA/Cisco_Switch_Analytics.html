HIGH #3 High TCN (Topology Change Notification) activity: 476 events in logs

Area: Spanning Tree

Detail: Excessive TCNs flush the MAC table causing temporary flooding on ALL ports, dramatically increasing CPU and broadcast traffic. Common cause: access port connected to a hub/IP phone cycling.

Recommendation: Enable 'spanning-tree portfast' on all access ports and 'spanning-tree bpduguard enable' to prevent non-switch devices from triggering TCNs. Check 'show spanning-tree detail | inc exec|occur'.

HIGH #4 BPDU Guard not enabled globally

Area: Spanning Tree

Detail: Without BPDU Guard on PortFast ports, a rogue switch or misconfigured device can trigger STP topology changes and potentially become root bridge.

Recommendation: Apply globally: 'spanning-tree portfast bpduguard default'. This shuts the port immediately if a BPDU is received on a PortFast port.

INFO #6 Loop Guard not enabled

Area: Spanning Tree

Detail: Loop Guard protects against unidirectional link failures that could cause a blocked port to incorrectly transition to forwarding.

Recommendation: Enable: 'spanning-tree loopguard default'. Particularly important on uplinks and trunk ports.

Remediation Priority Checklist

  1. Critical first: Resolve CAM table overflow and CPU >90% before any other work.
  2. Half-duplex: Set explicit duplex full + speed on ALL uplinks — never leave auto/auto on trunks.
  3. BPDU Guard: spanning-tree portfast bpduguard default on ALL switches in the domain.
  4. High error ports: Replace cables, check SFPs, verify NIC settings on connected servers.
  5. PortFast: spanning-tree portfast default eliminates 30-second port delays for end devices.
  6. Storm control: Configure per-port storm-control thresholds: storm-control broadcast level 20 on access ports.
  7. Loop Guard: spanning-tree loopguard default on all non-edge ports.
  8. Port security: Limit MAC per access port: switchport port-security maximum 3.
